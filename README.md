# UX2-VU-util

This program enables control over the proprietary Line 6 POD Studio UX2 VU Meters and Clip indicators. This program is still being developed and will be released soon.

## What works

- Sound card gets detected, vu meters and clip lights work correctly.
- All program values are parametrized for ease of change.
- Sound card gets redetected after it gets plugged in again.
- Only sound card audio exit gets visualized on the meters.

## What doesn't

- Input monitoring with meters.

## What's missing

- Systemd install script.
